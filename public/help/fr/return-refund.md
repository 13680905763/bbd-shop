# Service de retour/échange 5 jours bbdbuy

## 1. Qu’est-ce que la garantie de retour/échange 5 jours ?

Le service de retour/échange 5 jours est offert par certains vendeurs tiers. Le retour ou l'échange peut être demandé dans les 7 jours suivant la livraison (soit 5 jours après l'entrée en entrepôt).

## 2. Mon produit est-il éligible ?

### ✅ Produits éligibles

- Le vendeur accepte les retours
- L’article est en état revendable
- Stocké depuis moins de 5 jours
- Les frais de retour sont à la charge du client (même si la livraison initiale était gratuite)

### ❌ Produits non éligibles

| Type | Description |
| :--- | :--- |
| Produits personnalisés | ex. vêtements personnalisés |
| Articles sans étiquette/accessoires | ex. étiquette coupée, emballage manquant |
| Articles d’occasion | Tous non éligibles |
| Produits étrangers | Achats hors Chine continentale non éligibles |
| Sous-vêtements | Inclut chaussettes, leggings, etc. |
| Produits adultes | Non éligibles |
| Nourriture & livres en gros | ex. plus de 15 livres |
| Articles ouverts | Doivent répondre à des exigences spéciales |

## 3. Comment demander un retour/échange ?

Vous pouvez faire une demande dans les 5 jours (120 heures) suivant le statut « Stocké ». Passé ce délai, elle ne sera pas acceptée.

## 4. Frais de retour/échange

| Type de Service | Composition des Frais |
| :--- | :--- |
| Retour sans condition | Frais de première expédition + frais retour + 5 RMB de service |
| Échange sans condition | Première expédition + frais retour + réexpédition vendeur + 5 RMB de service |

> **Note**
>
> Même si la commande initiale bénéficiait de la livraison gratuite, les frais d’envoi initiaux doivent être remboursés.

## 5. Responsabilité & frais

| Responsable | Exemple | Qui paie |
| :--- | :--- | :--- |
| Client | Ne veut plus / erreur / budget | Frais aller-retour + service à sa charge |
| Vendeur | Erreur d’envoi / défaut | À la charge du vendeur (sauf exceptions) |
| Autre | Dommages durant transport domestique | Selon le cas |

## 6. Remarques & FAQ

- Le montant remboursé correspond au montant réellement payé.
- Le retour/échange dépend de l’accord du vendeur.
- Un solde suffisant est requis pour régler les frais associés.
- Certains produits nécessitent un emballage spécial ; sans cela, le retour peut être refusé.
