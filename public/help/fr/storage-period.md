# Combien de temps les marchandises peuvent-elles être stockées dans l'entrepôt bbdbuy ?

Les marchandises peuvent être stockées dans l'entrepôt bbdbuy jusqu'à **90 jours** (période de stockage standard), calculée à partir du jour où le statut de la commande passe à « Stocké ».

Si la période de stockage atteint entre **90 et 180 jours**, le système fournira automatiquement une **période de grâce de 28 jours** pour prolonger le stockage. Si ce n'est pas traité après la période de grâce, la commande sera considérée comme abandonnée.

Si vous **ne soumettez pas pour expédition dans les 90 jours** ou **ne payez pas les frais de stockage prolongé**, les marchandises seront considérées comme abandonnées.

**La limite de stockage maximale est de 180 jours.**
Après cette période, bbdbuy ne fournira plus aucun service d'entreposage ou de stockage, et les marchandises seront automatiquement considérées comme abandonnées.

<span className="text-red-500 font-medium">Remarque : bbdbuy se réserve le droit de nettoyer périodiquement les marchandises abandonnées.</span>
