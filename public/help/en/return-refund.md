# bbdbuy 5-Day Return/Exchange Service

## 1. What Is the 5-Day Return/Exchange Guarantee?

The 5-day return/exchange guarantee is a service provided by some third-party sellers. You may apply for return/exchange within 7 days of delivery (i.e., within 5 days after the item enters the warehouse).

## 2. Is My Product Eligible for Return/Exchange?

### ✅ Eligible Products

- Seller supports returns
- Item remains in resellable condition
- Item has been in warehouse for no more than 5 days
- Return shipping fee is borne by the user (even if the original order offered free shipping)

### ❌ Ineligible Products

| Type | Description |
| :--- | :--- |
| Customized products | e.g. customized clothing, requires negotiation with seller |
| Items with removed tags/accessories | e.g. clothing without hang tags, missing packaging |
| Second-hand items | Not eligible for return/exchange |
| Overseas products | Non-mainland purchases are not eligible |
| Underwear | Includes underwear, socks, leggings |
| Adult products | Not eligible |
| Food & bulk books | e.g. snacks, candy, more than 15 books |
| Opened items | Must meet special standards or will not be accepted |

## 3. How to Apply for a Return/Exchange?

You may apply within 5 days (120 hours) after the item status becomes 'Warehoused'. Requests submitted after the deadline will not be accepted.

## 4. Return/Exchange Fee Explanation

| Service Type | Fee Composition |
| :--- | :--- |
| Unconditional Return | Seller’s first shipping cost + warehouse return shipping fee + 5 RMB service fee |
| Unconditional Exchange | Seller’s first shipping cost + warehouse return shipping fee + seller’s resend shipping cost + 5 RMB service fee |

> **Note**
>
> Even if the original order included free shipping, the first shipping cost must be reimbursed.

## 5. Responsibility & Fee Allocation

| Responsible Party | Example | Who Bears the Cost |
| :--- | :--- | :--- |
| Customer | Doesn't want / Wrong item / Budget issue | Customer bears shipping both ways + service fee |
| Seller | Wrong item or quality issue | Seller bears costs (exceptions apply) |
| Other | Damage during domestic shipping | Handled per situation |

## 6. Notes & FAQ

- Refund amount is based on the actual amount paid.
- We can only process return/exchange if the seller agrees.
- Ensure sufficient account balance to pay return shipping and service fees.
- Some items require special return packaging; failure to meet requirements may result in rejection.
