# How long can goods be stored in bbdbuy warehouse?

Goods can be stored in bbdbuy warehouse for up to **90 days** (standard storage period), calculated from the day the order status changes to "Warehoused".

If the storage period reaches between **90–180 days**, the system will automatically provide a **28-day grace period** for extending storage. If it is not processed after the grace period, the order will be considered abandoned.

If you **do not submit for shipment within 90 days** or **do not pay the extended storage fee**, the goods will be considered abandoned.

**The maximum storage limit is 180 days.**
After this period, bbdbuy will no longer provide any warehousing or storage services, and the goods will be automatically considered abandoned.

<span className="text-red-500 font-medium">Note: bbdbuy reserves the right to periodically clear abandoned goods.</span>
