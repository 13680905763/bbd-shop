# 保价包裹 / 免费保险赔偿标准

购买 bbdbuy Care Service 的保价包裹，以及未购买的免费保险，赔付标准如下：

**bbdbuy保险及赔偿细则**

1. 若商品在bbdbuy入库后丢失，经工作人员确认丢件后，全额赔偿商品费用，如bbdbuy没有入库扫描记录的包裹，无法提供查件和赔偿服务；
2. 未上网/未提取及扣关无法放行：25天没有末端提取信息退运费，30天没有末端提取信息赔偿6$/kg。
3. 中断更新：尾程服务商提取运输后断更超7个工作日未更新物流轨迹，向服务商开查，开查7日后无结果，按4kg以内（包括4kg）赔偿6$/kg，4kg以上赔偿20欧元/票。
   *其中以下问题及国家不做赔付：收件人地址不详/不正确问题，收件人联系方式问题、派送收件人不在场问题，到达待取问题，到达邮局收件人未及时取件问题、退回途中及重派问题、国家：西班牙、意大利、法国，不在此断更赔付条件内。*
4. 不含海关查验、当地工人罢工、天气原因等不可控因素导致超时提取情况；

**二、免责申明**

1. 不可抗力因素：包括但不限于：战争，天灾（包括地震，气旋，风暴，洪水等）核辐射，核爆炸，核污染及其它放射性污染造成的损失等原因造成的直接或间接损失或损害;
2. 用户无法提供赔付所需相关证明的；
3. 超出申请赔付时效（包裹签收7天内或者寄送45天内未查询又未提出赔偿要求的），包裹在申请赔偿期间被正常签收的；
4. 派送后遭受盗窃或不明原因失踪的；
5. 寄递的物品含有不可投保品类的商品、寄递的物品违反禁寄或限寄规定的，经主管机关没收或依照有关法规处理的；
6. 由货主的责任、故意行为或过失所造成的损失或所寄物品本身的原因造成邮件损失或丢失；
7. 其他不属于赔偿责任的情形的

*最终赔偿以物流公司与 bbdbuy 的理赔标准为准。*
